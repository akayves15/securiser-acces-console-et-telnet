# lab-securiser-acces-console-et-telnet

## Objective
Ce lab a pour objectif de montrer l'importance de la sécurisation du mode privilège, des accès console et telnet

## Compétences apprises
- Navigation dans l'IOS de CISCO
- Configuration et sécurisation du mode privilège
- Configuration et sécurisation de l'accès console
- Configuration de la ligne VTY et sécurisation l'accès telnet 
- Configuration de l'interface VLAN 1 pour un accès distant au switch.

## Outils utilisé(s)
- Cisco packet tracer
- ordinateur portable.
- switch
- câble console
- câble RJ45
